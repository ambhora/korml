# Reference

This section is the normative language reference for Korml.

It is about the language itself: source text, lexical structure, grammar, and document model.
It intentionally does not document the Python API, implementation classes, command-line interface, or internal module layout.

The reference is organized as follows:

- [Grammar Reference](grammar.md): token-level grammar for Korml documents.
- [Lexical Structure](lexical-structure.md): characters, whitespace, comments, indentation, and scalar forms.
- [Document Model](document-model.md): the abstract values represented by a Korml stream.
